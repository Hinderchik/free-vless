## 🚀 Как использовать

### Для Happ:
1. Откройте Happ
2. Нажмите **"Подписки"** → **"Добавить подписку"**
3. Вставьте ссылку выше
4. Нажмите **"Обновить"**

### Для Hiddify:
1. Откройте Hiddify
2. Нажмите **"+"** → **"Импорт из URL"**
3. Вставьте ссылку выше
4. Нажмите **"Добавить"**
